# Research

SpecSync 5 does not measure extensionless Bash files, so a percentage above zero would be vacuous. The correct contract threshold is advisory zero with an explicit rationale, while deterministic native checks remain blocking. Live location and forecast requests require independent network authorization and must not be folded into the normal pull-request gate.
